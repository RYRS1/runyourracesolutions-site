# Run Your Race Solutions — V3

Industrial / avant-garde redesign for Netlify.

## Design direction
- Concrete grey / washed charcoal / bone white
- Single muted phosphor-green accent
- No blue gradients
- Monolithic asymmetric grid
- Oversized condensed typography
- Tiny monospace micro-data
- Grain / thermal-camera / system-status visual language
- Three-link lowercase navigation
- User-supplied real trailer photography and logo

## Deploy
Upload the contents of this folder to Netlify, or drag the ZIP into Netlify.

The contact form uses Netlify Forms and requires no backend.

## V4 Contact Experience
- Commercial security quote intake
- Property/site information
- Site size
- Service selection
- Desired start date
- Detailed project/security concern
- Required-field validation
- Netlify honeypot spam protection
- Mobile-clickable phone and email
- Dedicated confirmation state after submission
